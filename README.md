# erniez28.de

Website von Sascha „Ernie“ Ernst, Freelance Shopware 6 Entwickler für Agenturen und Shopbetreiber.

- **Stack:** Astro (statisches HTML), GSAP + ScrollTrigger, Lenis, eine React-Insel für den Projektbrief
- **Lokal starten:** `npm install` und `npm run dev` → http://localhost:4321
- **Build:** `npm run build` → `dist/` (siehe `DEPLOYMENT.md`)

## Inhalte pflegen

| Datei | Inhalt |
|---|---|
| `src/data/e28.js` | Verfügbarkeit, Fakten, Leistungen, Fallstudien-Kurzfassungen, Momentum-Log, Ablauf, FAQ |
| `src/data/pages.js` | Leistungs-Detailseiten, Fallstudien, Journal-Artikel |
| `src/data/quest.js` | Welten und Stationen von „Ernies Quest“ (/whoami) |
| `src/data/sprites.js` | Pixel-Sprites (Zeichenraster, Farben kommen aus CSS) |
